# Wpal

Per-workspace Background (default/custom/random) and auto-launched pane layouts for empty workspaces.

An omarchy bar plugin (`kinds`: service, bar-widget).

- **id**: `chad.silverstone`
- **version**: 1.0.0
- **author**: chad
- **license**: MIT
- **entry points**: `Service.qml` (service), `BarWidget.qml` (bar widget)

## Install

Copy this plugin's files into `~/.config/omarchy/plugins/chad.silverstone/`.
